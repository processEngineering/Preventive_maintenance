## 🔄 Key Changes

### 1. Database Layer
```
BEFORE: PostgreSQL (Supabase)
AFTER:  MySQL/MariaDB (local or remote)
```

### 2. Authentication
```
BEFORE: Supabase Auth (email/password via Supabase)
AFTER:  JWT Tokens (custom auth via Flask backend)
```

### 3. API Client
```
BEFORE: Supabase SDK (@supabase/supabase-js)
AFTER:  Custom APIClient (fetch-based, in supabase-client.js)
```

### 4. Dependencies

**Removed:**
- `psycopg2-binary` (PostgreSQL driver)
- `@supabase/supabase-js` (not in requirements, but SDK imports removed)

**Added:**
- `mysql-connector-python` (MySQL driver)
- `PyJWT` (JWT token handling)
- `werkzeug` (password hashing)

## 🚀 Next Steps

### Step 1: Set Up MariaDB

```bash
# 1. Create database
CREATE DATABASE preventive_maintenance CHARACTER SET utf8mb4;

# 2. Create users table
USE preventive_maintenance;
CREATE TABLE users (
    id INT PRIMARY KEY AUTO_INCREMENT,
    email VARCHAR(255) UNIQUE NOT NULL,
    password VARCHAR(255) NOT NULL,
    full_name VARCHAR(255),
    role VARCHAR(50) DEFAULT 'user',
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);

# 3. Import your data
mysql preventive_maintenance < backup.sql
```

### Step 2: Configure Environment

```bash
cd mtc-checklist/backend
cp .env.example .env

# Edit .env with your MariaDB credentials
# DB_HOST=localhost
# DB_NAME=preventive_maintenance
# DB_USER=root
# DB_PASSWORD=your_password
# DB_PORT=3306
```

### Step 3: Install Dependencies

```bash
pip install -r requirements.txt
```

### Step 4: Test Server

```bash
python server.py

# Expected output:
# 🚀 Server Lokal AKG Maintenance AKTIF!
# Environment: development
# Database: localhost:3306/preventive_maintenance
```

### Step 5: Test API

```bash
# Health check
curl http://localhost:5000/api/health

# Should return: {"status": "ok", "message": "..."}
```

## 📊 Architecture Changes

### Old Architecture (Supabase)
```
Frontend (HTML/JS)
    ↓
Supabase SDK
    ↓ (Network)
Supabase Cloud (PostgreSQL)
```

### New Architecture (MySQL)
```
Frontend (HTML/JS)
    ↓
Custom API Client (supabase-client.js)
    ↓ (Network - HTTP/HTTPS)
Flask Backend (Python)
    ↓
MySQL Database (Local or Remote)
```

---

## 🔐 Authentication Flow

### Old Flow (Supabase Auth)
```
1. User enters email/password
2. Frontend sends to Supabase Auth API
3. Supabase returns auth token
4. Token stored in localStorage
5. Used for API requests
```

### New Flow (JWT)
```
1. User enters email/password
2. Frontend sends to /api/auth/login
3. Flask checks MySQL users table
4. Returns JWT token
5. Token stored in localStorage
6. Used for API requests (Authorization header)
```

## 🐛 Troubleshooting

### Issue: "ModuleNotFoundError: No module named 'mysql'"
```bash
# Solution: Install dependencies
pip install -r requirements.txt
```

### Issue: "Can't connect to MySQL server"
```bash
# Check MariaDB is running
# Check .env credentials are correct
# Check DB_HOST, DB_USER, DB_PASSWORD
```

### Issue: "Table 'users' doesn't exist"
```bash
# Solution: Create the users table
mysql preventive_maintenance < create_users.sql
```

### Issue: "Invalid token" / "Token expired"
```bash
# Tokens expire after 24 hours
# User needs to login again
```

### Issue: Frontend says "Can't connect to server"
```bash
# Check Flask server is running
# Check API_URL in supabase-client.js points to localhost:5000
# Check CORS is enabled in server.py
```
